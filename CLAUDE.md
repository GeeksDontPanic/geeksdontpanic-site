# GDP Project Context

## Tech Stack
- Next.js 14+ (App Router)
- React
- Tailwind CSS (if applicable)
- JSON-driven data (lore.json, ticker.json)

## Coding Standards
- Clean, minimal dependencies
- Configurable timing blocks at top of components
- Terminal/brutalist aesthetic
- No unnecessary abstractions

## Narrative Style
- Cryptic, archival tone
- Inspired by Dune, Halo terminals, Pathfinder
- Subtle worldbuilding, slow-burn reveals

## Git Workflow
- Always commit before major changes
- Update changelog.md with changes
- Use descriptive commit messages

## File Structure
- `/app` - Next.js pages
- `/components` - Reusable components (Ticker, etc.)
- `/data` - lore.json, ticker.json
- `/public` - Assets

## Design Philosophy
Minimalist, brutalist, terminal-like, cinematic. High contrast, clean grids, industrial aesthetic.
